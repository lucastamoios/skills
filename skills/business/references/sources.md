# Sources and adaptations

The primary public pages and upstream skill files below were consulted on 2026-11-03.
The full books were not read as part of this implementation. These skills use original
wording and a selective synthesis, not copied chapters, canvas artwork, or a promise
of complete fidelity to every author's method. Recheck evolving repository instructions
and market claims when they matter; the retrieval itself follows the shared contract.

## Primary foundations

| Source | Supported use in this suite |
| --- | --- |
| [Eric Ries: Lean Startup principles](https://theleanstartup.com/principles) | The manager connects action to learning; experiments and reviews inform whether a hypothesis should change. |
| [Steve Blank: Customer Development is Not a Focus Group](https://steveblank.com/2009/11/30/customer-development-is-not-a-focus-group/) | Exploration tests beliefs about customers instead of treating feature requests as requirements. |
| [Rob Fitzpatrick: The Mom Test](https://www.momtestbook.com/) | The official book page supports its focus on useful, less biased customer conversations. Detailed interview prompts here are our synthesis; the book is further reading. |
| [Teresa Torres: Opportunity Solution Trees](https://www.producttalk.org/opportunity-solution-trees/) | The manager distinguishes outcome, opportunity, solution, and assumption test, using customer evidence. |
| [April Dunford: A Quickstart Guide to Positioning](https://aprildunford.substack.com/p/a-quickstart-guide-to-positioning) | Offer design starts from alternatives and relates differences to customer value, segments, and category. |
| [Strategyzer: Value Proposition Canvas](https://www.strategyzer.com/library/the-value-proposition-canvas) | Offer design separates the customer's job, pains, and gains from the proposed value map. |
| [Alex Osterwalder: Test Card](https://www.strategyzer.com/library/validate-your-ideas-with-the-test-card) | Experiments specify the hypothesis, method, measurement, and criterion before execution. |
| [Strategyzer: Learning Card](https://www.strategyzer.com/library/capture-customer-insights-and-actions-with-the-learning-card) | Reviews distinguish observations, interpretation, and subsequent action. |
| [Steve Blank and Alex Osterwalder: Mission Model Canvas](https://steveblank.com/2016/02/23/the-mission-model-canvas-an-adapted-business-model-canvas-for-mission-driven-organizations/) | Public-sector applications distinguish mission outcomes, beneficiaries, adoption, and budgets. |

The Lean Startup, The Startup Owner's Manual, The Mom Test, Continuous Discovery
Habits, Obviously Awesome, Value Proposition Design, and Testing Business Ideas are
related foundational reading. This list does not imply that their full contents
were ingested, reproduced, or verified here.

## Skill inspirations and deliberate changes

| Source | What we use and adapt |
| --- | --- |
| [Business Brainstorm](https://github.com/coreyhaines31/makerskills/blob/main/skills/business-brainstorm/SKILL.md) and [its framework](https://github.com/coreyhaines31/makerskills/blob/main/skills/business-brainstorm/references/framework.md) | We use portfolio fit, distribution, opportunity cost, and explicit unknowns. We omit the author's personality and portfolio assumptions, compulsory domain checks, and vote-based build verdict. |
| [PM Skills discovery](https://github.com/phuryn/pm-skills/blob/main/pm-product-discovery/commands/discover.md) | We connect ideas, assumptions, and experiments. We omit fixed idea quotas and mandatory stage checkpoints. |
| [PM Skills assumption prioritization](https://github.com/phuryn/pm-skills/blob/main/pm-product-discovery/skills/prioritize-assumptions/SKILL.md) | We use explicit assumptions and targeted tests. We do not copy its inconsistent confidence scales or treat a matrix quadrant as implementation authorization. |
| [Wondel.ai Lean Startup](https://github.com/wondelai/skills/blob/main/lean-startup/SKILL.md) | We use backward experiment planning. We replace its universal score and evidence ladder with claim-specific evidence and do not require concealing manual delivery. |
| [Startup Positioning](https://github.com/ferdinandobons/startup-skill/blob/main/startup-positioning/SKILL.md) | We reuse customer alternatives and prior context. We choose research depth by the decision rather than requiring a fixed sequence of waves and approvals. |
| [PM Brain](https://github.com/phuryn/pm-brain) | We use provenance and resumable decisions inside the existing Brain. We do not import migration, automatic commits, or scheduled maintenance. |
| The existing local `brainstorm` skill, maintained in `profile.paths.skills/brainstorm/SKILL.md`. | We retain conversational exploration, selective structure, and the next useful question. The business suite does not modify or require invoking the generic skill. |
