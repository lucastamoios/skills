# Private Context Conventions

Keep one topic per note. Use Markdown and a short title. Preserve source attribution and distinguish verified facts, decisions and open questions.

Task notes live in the configured tasks directory. Use the bundled task helper for task changes. Supported lanes are To Do, Today, In Progress, Review, Done, Delegated, Scheduled, Blocked and Maybe.

Read only context relevant to the request. Personal journals require explicit user scope. Keep credential values out of notes, task files, generated reports and public packages.
